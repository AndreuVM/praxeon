# Archivo Histórico de Benchmarks — PRAXEON v1.0 y previas

Este directorio almacena formalmente los resultados y reportes empíricos generados
durante fases de desarrollo previas a la modularización independiente v1.1.

Los resultados canónicos reproducibles de la versión actual se guardan en la raíz
de `benchmark_results/` con metadatos estrictos (commit SHA, config hash, hardware).
